# 🚀 PichOS (Core Linux)

Добро пожаловать в репозиторий **PichOS** — независимого, ультра-минималистичного дистрибутива Linux, собираемого вручную из голого ядра (по методологии Linux From Scratch) с мощным независимым пакетным менеджером **Nix** под капотом.

> **Статус проекта:** В разработке (Этап 1: Сборка ядра в песочнице VirtualBox)

---

## 🎯 Основная концепция
PichOS создается как «чистый холст» для двух главных задач: **Программирование** и **Игры**. Никакого лишнего фонового мусора, никаких принудительных обновлений как в Windows 11 — только абсолютный контроль над каждым процессом и максимальный FPS на моем железе.

### ⚙️ Моя конфигурация ПК (Целевое железо):
* **CPU:** AMD Ryzen 3 3100 (4 ядра / 8 потоков)
* **RAM:** 16 GB DDR4 @ 3200 MT/s
* **GPU:** NVIDIA GeForce GTX 1050 Ti

---

## 🛠️ Архитектура системы
1. **База:** Чистое ядро Linux (Kernel v6.x) + GNU coreutils.
2. **Управление пакетами:** Независимый пакетный менеджер **Nix** (детерминированная и изолированная установка софта).
3. **Драйверы:** Официальный проприетарный драйвер NVIDIA (вшивается на этапе сборки графического сервера).
